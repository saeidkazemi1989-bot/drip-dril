# سازنده گزارش بهبود فرآیند

ابزار وب فارسی (راست‌چین) برای ساخت گزارش بهبود فرآیند بردهای الکترونیکی خودرو —
ساختار گزارش مطابق فایل نمونه است، اما برای **هر محصول و هر فرآیند** (مونتاژ SMT،
لحیم‌کاری موجی/انتخابی، تست ICT، تست عملکردی، پوشش کانفورمال و...) قابل استفاده است.
اطلاعات و عکس‌ها را وارد کنید، تحقیق اینترنتی انجام دهید و فایل پاورپوینت
**قابل‌ویرایش** تحویل بگیرید.

## کار تدریجی (بخش‌بخش)

لازم نیست همه بخش‌ها را یکجا پر کنید:

- اطلاعات به‌صورت **خودکار** هم در مرورگر و هم روی سرور (پوشه `drafts/`) ذخیره می‌شود؛
  هر وقت برگشتید، کار ادامه پیدا می‌کند.
- با دکمه **«ذخیره پیش‌نویس»** می‌توانید چند پیش‌نویس با نام دلخواه نگه دارید و
  از لیست پیش‌نویس‌ها بارگذاری/حذف کنید.
- نقطه سبز کنار هر گام در منوی سمت راست یعنی آن بخش تکمیل شده است.
- دکمه **«خروجی با اطلاعات فعلی»** (بالای صفحه، همیشه در دسترس) در هر لحظه فایل
  کامل می‌سازد؛ بخش‌های پرنشده با جای‌خالی مشخص می‌شوند تا بعداً تکمیل شوند.
- در گام خروجی می‌توانید گزینه «فقط بخش‌های پرشده» را فعال کنید تا فقط اسلایدهای
  دارای اطلاعات ساخته شوند.

## اجرا

```bash
pip install -r requirements.txt
python3 app.py
```

سپس مرورگر را روی `http://localhost:5000` باز کنید.

## مراحل کار (۱۵ گام)

1. **اطلاعات پایه** — عنوان، شرکت، تاریخ، اعضای تیم
2. **معرفی محصول** — متن + عکس محصول
3. **معرفی دستگاه/فرآیند** — متن + عکس دستگاه + تاریخ راه‌اندازی
4. **معرفی قطعه — سازنده** — جدول شرح/شماره فنی/کد سازنده/نمره
5. **فاز ۱ انتخاب موضوع** — شرح ایرادات
6. **فاز ۲ توجیه دلایل انتخاب** — جدول اخطارهای کیفی
7. **فاز ۳ درک وضعیت جاری** — وضعیت سازنده، مقایسه قبل/بعد، قابلیت فرآیند (Cp/Cpk)،
   هزینه‌ها، روند PPM، مقایسه تامین‌کننده‌ها، عکس عیوب
8. **فاز ۴ انتخاب هدف** — اهداف کمی + گام‌های اصلی
9. **فاز ۵ تجزیه و تحلیل** — پارتو، نمودار ایشیکاوا (6M)، بررسی علل، عکس‌ها
10. **فاز ۶ اقدام اصلاحی** — اقدامات قبلی/جدید + کارت‌های اقدام با عکس قبل/بعد
11. **فاز ۷ تایید تاثیرات** — نمودار PPM پس از اصلاح
12. **فاز ۸ استانداردسازی** — جدول مدارک (FMEA/CP/LPA و...)
13. **فاز ۹ خلاصه و اقدامات آینده**
14. **تحقیق اینترنتی و بهینه‌کاوی** — جستجوی زنده در اینترنت + پایگاه دانش داخلی
    (عیوب وان قلع، IPC-A-610، ایشیکاوا، 8D، DOE و...)
15. **خروجی** — دانلود فایل PPTX

## خروجی

- فایل `.pptx` با متن‌ها، جدول‌ها و نمودارهای **Native و قابل ویرایش** در PowerPoint
  (نه تصویر اسلاید) — ساختار اسلایدها مطابق فایل نمونه است.
- دکمه «داده نمونه (فقط مثال ساختار)» داده‌های فایل نمونه را پر می‌کند تا بلافاصله
  خروجی را ببینید و ویرایش کنید — این داده فقط مثال است، نه مبنای گزارش شما.
- خروجی/ورود JSON برای ذخیره و ادامه کار در دفعات بعد.
- ذخیره خودکار در مرورگر (localStorage) + پیش‌نویس روی سرور.

## فایل‌ها

| فایل | توضیح |
|---|---|
| `app.py` | سرور Flask (رابط وب + API تولید PPTX + جستجوی تحقیق) |
| `pptx_builder.py` | سازنده فایل پاورپوینت قابل‌ویرایش |
| `templates/index.html` | رابط کاربری فارسی راست‌چین |
| `static/app.js` / `static/style.css` | منطق و ظاهر فرانت‌اند |
| `make_sample.py` | ساخت فایل نمونه خروجی از داده‌های NBCM |
| `sample-output.pptx` | نمونه خروجی آماده (۲۸ اسلاید) |
| `گزارش کیفی وان قلع جدید...pptx` | فایل نمونه اصلی کاربر (مرجع ساختار) |

## تحقیق اینترنتی

گام ۱۴ دو منبع دارد: جستجوی زنده در اینترنت (DuckDuckGo) و پایگاه دانش داخلی
با یافته‌های تحقیق تخصصی برای فرآیندهای مختلف برد الکترونیکی خودرو:
عیوب لحیم‌کاری (گلوله قلع، پل قلع، حفره، عدم ترشوندگی، نفوذ قلع)، مونتاژ SMT
(قبرسنگی، پروفایل ریفلو)، تست ICT/AOI و تست عملکردی، پوشش کانفورمال، قواعد طراحی
PCB، معیارهای IPC-A-610، ابزارهای 8D/ایشیکاوا/پارتو، قابلیت فرآیند، DOE و
IATF 16949/APQP.
خلاصه یافته‌ها و منابع در اسلاید «تحقیق اینترنتی و بهینه‌کاوی» خروجی قرار می‌گیرد.
